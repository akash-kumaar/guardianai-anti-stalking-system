# Guardian AI

Guardian AI is a personal safety application built using Flutter. I started this project to explore how mobile technology and AI can be used to improve personal security and help users document potentially unsafe situations.

The current version focuses on evidence collection and emergency response features. Users can access a live camera feed, capture photos as evidence, view captured images within the app, and maintain a basic incident log with timestamps.

## Current Features

* Live camera feed
* Evidence capture
* Evidence preview
* Timestamp logging
* Threat monitoring interface
* Emergency SOS screen

## Planned Features

* GPS location tracking
* Face detection
* Person tracking
* Evidence gallery
* Automated evidence collection
* AI-assisted threat analysis

## Built With

* Flutter
* Dart
* Camera Plugin
* Geolocator
* Shared Preferences

## Why I Built This

The idea behind Guardian AI is to create a tool that can help people feel safer in situations where they may be uncomfortable or concerned about being followed. While the project is still under development, the goal is to eventually combine evidence collection, location tracking, and AI-based monitoring into a single mobile application.

## Status

This project is currently under active development and new features are being added regularly.
